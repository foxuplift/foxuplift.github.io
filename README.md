# FoxUplift Portfolio

A static portfolio website built with plain HTML, CSS and JavaScript for free hosting on GitHub Pages.

## Included files

- `index.html` — one-page homepage
- `case-studies/numi.html` — reusable case-study template
- `assets/css/style.css` — full responsive design system
- `assets/js/script.js` — navigation, header and scroll reveals
- `404.html` — custom not-found page

## Before publishing

Replace:

1. `your-email@example.com`
2. The LinkedIn placeholder URL
3. Placeholder project copy and metrics
4. Placeholder testimonials
5. Resume file at `assets/documents/raj-kumar-resume.pdf`
6. Client website URL in the case-study template
7. Placeholder artwork with real optimised images

## GitHub Pages deployment

Upload the contents of this folder to:

`https://github.com/foxuplift/foxuplift.github.io`

Then open:

`Settings → Pages → Deploy from a branch → main → /root`

The live website address will be:

`https://foxuplift.github.io`

## File naming

Use lowercase filenames with hyphens:

- `numi-logo.webp`
- `meta-ads-dashboard.webp`
- `raj-kumar-resume.pdf`

Avoid spaces, brackets and files called `final-final-2`.

## Adding a case study

1. Copy `case-studies/numi.html`
2. Rename it, for example `vocalmist.html`
3. Replace the content and metadata
4. Add the new page URL to the matching card on `index.html`
